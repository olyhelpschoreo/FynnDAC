One change · Fynn's web developer

Point fynnfamily.com/dadcouncil at the page

Nothing needs to be deployed or hosted — the page is hosted already. All that is needed is a redirect. In the hosting block of firebase.json, add:

"redirects": [
  {
    "source": "/dadcouncil{,/**}",
    "destination": "https://olyhelpschoreo.github.io/FynnDAC/",
    "type": 302
  }
]

Then deploy as usual. If a redirects array already exists, add this entry to it. The {,/**} pattern makes /dadcouncil and /dadcouncil/ both work, along with anything typed after them.

Please use 302, not 301. A 301 tells browsers the move is permanent, and they cache it almost indefinitely — if the page ever moves again, anyone who visited once keeps being sent to the old address, and it is very hard to undo. A 302 behaves identically for visitors and keeps the option open.
